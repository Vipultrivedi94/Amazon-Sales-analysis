# 📊 Amazon Sales Data Analysis

## 📌 Overview

An end-to-end data analytics project using an **Amazon sales dataset from Kaggle**
to analyze sales performance, revenue trends, product categories, customer segments, and order behavior.

The project includes **data cleaning and analysis using Python & Pandas**,
business analysis using **PostgreSQL & SQL**, and an interactive **Power BI dashboard** for visualizing key insights.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* PostgreSQL
* Power BI

## 🔍 Key Analysis

* Sales & revenue performance
* Category-wise sales analysis
* Monthly revenue trends
* B2B vs B2C comparison
* Order & quantity analysis
* Cancellation rate
* Interactive Power BI dashboard

This project strengthened my practical skills in **Data Cleaning, 
Exploratory Data Analysis, SQL, Data Visualization, and Business Intelligence**
